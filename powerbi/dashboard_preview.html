Production Deployment Prerequisite: SKU & Campaign Attribution

To unlock true product-level drilldown (e.g., comparing Echo Dot 5th Gen vs Fire TV Stick 4K Max) and marketing campaign ROI (e.g., Prime_Day_2026_Promo), the data ingestion layer must connect to a production catalog service or transactional database that supplies genuine ASINs/SKUs and UTM campaign parameters. The database schema in PostgreSQL is fully prepared with foreign keys and indexes to consume these tables seamlessly.

Model Evaluation Integrity & Ethical Governance

Ground Truth Principle: CustomerVoice AI adheres strictly to the rule that model performance metrics may only be computed from real, human-annotated validation sets. No artificial validation sets were generated. As larger human-labeled golden sets are established, running python scripts/run_evaluation.py automatically updates the model_metrics table in PostgreSQL, instantly propagating new benchmark curves to Power BI.
